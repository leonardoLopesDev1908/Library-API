RESTful:
    conjunto de princípios e boas práticas para seguir padrões na criação de APIs

Contrato de API:
    especificação que define regras e diretrizes para integração entre cliente e API. 
    Quais verbos http usados,
    quais response codes podem ser usados
    quais headers e bodys

Identificação de recursos
    Qual url será usada para acessar o recursos

    utilizar substantivos no plural no lugar de verbos: 
        operação -> Cadastras, URL Incorreto: /cadastro-cliente/salvar, URL Correto: /clientes

    Hierarquia:
        /pedidos/{id}/itens
        /usuario/{id}/pedidos

    Ids:
        /pedidos/{id}
        /clientes/{id}

    URLs simples e legíveis:
        /pedidos/operacoes
        /dados/importacoes
    
    Parametro de url: utilizar Query Params quando não for identificador de recursos
        /clientes?nome=jose
        /autores?nacionalidade=Brasileira
        /livros?ano-publicacao=1980&autor=Mario


Metodos HTTP apropriado

    Cadastrar cliente-> POST /clientes

    Atualizar cliente-> PUT /clientes/{id}

    Dados do cliente-> get /clientes/{id}

    Excluir cliente-> DELETE /clientes/{id}

    Pesquisa cliente-> GET /clientes?nome=fulano&ativo=true 

Codigo de resposta apropriado 

    Cadastrar cliente-> Sucesso: 201, 200; Erro: 400, 409, 422

    Atualizar-> Sucesso: 204, 200; Erro: 400, 409, 422

    Dados do cliente-> Sucesso: 200; Erro: 404

    Excluir-> Sucesso: 204, 200; Erro: 404, 400, 409

    Pesquisa -> Sucesso: 200, Erro: Não tem

    Autenticação-> Sucesso: 200; Erro: 401

    Não tratado: Sucesso: Não tem; Erro: 500
