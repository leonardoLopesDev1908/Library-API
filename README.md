# 📚 Library-API

Este projeto é uma primeira experiência com a construção de uma API utilizando **Spring Framework**.

O sistema realiza o **gerenciamento de autores e livros**, com foco em operações **CRUD** e implementação de **autenticação com Google** via OAuth2 e **token JWT** para segurança.

---

## 🚀 Tecnologias Utilizadas

- **Spring Boot** – Configuração rápida e simplificada de projetos Spring
- **Spring Data JPA** – Persistência de banco de dados
- **Spring Security** – Autenticação e autorização
- **Spring Authorization Server** – Autorização com suporte a JWT
- **OAuth2** – Autenticação via terceiros (Google)
- **Lombok** – Redução de boilerplate no Java
- **PostgreSQL** – Banco de dados relacional

---

## 🔐 Funcionalidades

- Login com **Google OAuth2**
- Geração e validação de **JWT**
- Endpoints RESTful com **CRUD de Autores e Livros**
- Segurança em rotas com controle de acesso
